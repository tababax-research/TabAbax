# Changes

## 1.0.0

Private inference release of TabAbax.

The package exports `TabAbaxClassifier` and `TabAbaxRegressor`. Pre-training, fine-tuning, forecasting, and explanation entry points are not included. Checkpoints are not included.

`LICENSE` is a commercial-use template for review. `requirements.txt` lists the inference dependencies. Omitting `model_path` downloads `tababax-classifier.ckpt` or `tababax-regressor.ckpt` from `tababax-ai/tababax`.
